🎵 Digital Music Management Application

A simple Java-based music playlist management system developed using Object-Oriented Programming (OOP) concepts. This application allows users to create playlists, add songs, display song details, and shuffle playlists for a random listening experience.

🚀 Features
Add songs with title and artist information
Display all songs in the playlist
Shuffle playlist randomly
Console-based user interface
Demonstrates OOP principles such as:
Encapsulation
Aggregation
Abstraction
🛠️ Technologies Used
Java
Object-Oriented Programming (OOP)
Arrays
Scanner Class
Random Class
📂 Project Structure
Song Class – Stores song details (title and artist).
Playlist Class – Manages a collection of songs and provides playlist operations.
MusicApp Class – Handles user interaction and program execution.
🎯 Learning Objectives

This project was created to understand how real-world applications can be designed using Java OOP concepts. It demonstrates data encapsulation, object aggregation, array management, and basic playlist operations.

🔮 Future Enhancements

▶️ How to Run

Compile the program:

javac MusicApp.java

Run the program:

java MusicApp
Enter song details and enjoy managing your playlist!
